НЕЙРО-МАКС — офлайн-генератор картинок по промпту (native, ONNX Runtime)
Приложение: Офлайн Арт (com.apkcreator.offlineart)

ЧТО ЭТО: настоящий Android-проект (Kotlin). Нейросеть LCM-Dreamshaper v7
(дистиллят Stable Diffusion: 4 шага вместо 30) работает ПРЯМО НА ТЕЛЕФОНЕ,
без интернета после первой загрузки модели. Стили: фото, аниме, фэнтези,
киберпанк, живопись. Русский и английский промпты.

ЧЕСТНЫЕ ЦИФРЫ (замерены с HuggingFace, не придуманы):
- UNet fp32: 3 438 411 520 байт (~3.2 ГБ)
- текстовый кодер fp32: 492 588 002 байт (~470 МБ)
- VAE-декодер fp32: 198 078 038 байт (~189 МБ)
- токенизатор + словарь: ~2.7 МБ
- ИТОГО fp32-стек: ~4.13 ГБ. В 150 МБ нейрофото не влезает физически:
  открытых text-to-image моделей такого размера не существует.
- fp32 UNet (3.4 ГБ) в память телефона НЕ влезет: нужен планшет с 8+ ГБ RAM,
  либо квантованные int8-веса (~1 ГБ, UNet ~860 МБ + кодер ~120 МБ + VAE ~70 МБ).
- APK самого приложения: ~40-60 МБ (рантайм onnxruntime-mobile 1.18.0).
- Скорость: на CPU fp32 — минуты на картинку 512px; int8 + NNAPI — быстрее.

КАК СОБРАТЬ APK (наш one-click builder так не умеет — только через облако):
1. Распакуйте zip, создайте репозиторий на github.com, загрузите всё.
2. Вкладка Actions → Build NeuroMax APK → Run workflow (или git push).
3. Заберите neuromax-debug из Artifacts. Установка вручную.
4. Первый запуск: только по Wi-Fi (опция в приложении), ~4.1 ГБ fp32.
   Дальше — airplane mode, всё считается на процессоре/ускорителе.

КАК УМЕНЬШИТЬ ДО ~1 ГБ (int8, для телефонов):
1. На ПК: pip install optimum[onnxruntime]
2. optimum-cli export onnx --model SimianLuo/LCM_Dreamshaper_v7 --task stable-diffusion lcm_int8/
3. Квантуйте UNet/text-encoder/vae в int8 (см. доку optimum, dynamic quantization).
4. Залейте файлы на HuggingFace, впишите URL и размеры в app/src/main/assets/models.json
   (формат тот же: name/url/size) и пересоберите через Actions.

ПРОВЕРЕНО АВТОРОМ КОНСТРУКТОРА:
- URLs и размеры файлов — реальны (проверены запросом к HuggingFace).
- Версия onnxruntime-mobile 1.18.0 — реально существует в Maven.
- Входы UNet (sample/timestep/encoder_hidden_states → out_sample) — из графа модели.
- Формулы планировщика LCM и масштаб VAE 0.18215 — из конфигов модели.
- Токенизатор пословно сверен с эталоном: 73/73 промптов бит-в-бит,
  включая русский, Caps, эмодзи, цифры, пунктуацию (в приложении едет
  встроенный Kotlin-порт + штатный tokenizer/model.onnx как основной путь).
- Сам Kotlin на устройстве НЕ проверялся (у конструктора нет Android SDK):
  после сборки погоняйте и сообщите — допилим.
